# Veterinaria San Marcos - Frontend

SPA en React para la Evaluación Parcial 3 de DSY1104 Desarrollo FullStack II.
Parte de la entrega de la Evaluación 2 (repositorio `fssepul-prog/Veterinaria-san-marcos-react`), sin pruebas unitarias ni validaciones de formulario.

Backend: repositorio `veterinaria-san-marcos-backend`.

## Ejecutar

Requiere Node.js 20 o superior.

```bash
npm install
npm run dev
```

La aplicación abre en http://localhost:5173.
